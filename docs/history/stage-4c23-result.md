## 별도 로컬 관찰

영구 명령이나 진단 프로토콜을 추가하지 않고, 비공개 하네스 모듈의 한정 계측을 사용했다. 실제 요청 OID에 대해서만 기존 이진 검색과 원본 index의 독립 바이트 선형 검색을 대조한다. index 원본 Buffer의 보유·해제는 기존 공유 예산으로 계수하고, 불일치·한도 초과는 거부한다. 실패 직전 최종 파일·경로 검사를 추가했으며 기존 metadata·메모리·읽기·시간 한도를 유지했다. 실제 실행 전 정상 pack과 commit/tree/blob 누락 등 5개 합성 사례 및 정적 검토를 통과했다.

허용된 선택4파일의 별도 진단1회에서 `INVALID_SOURCE/object_lookup`과 blob 부재를 관찰했다. 6개 pack index의 요청 검색을 선형 검색과 대조해 불일치가 없었고, loose 위치와 해당 index 집합에서 요청 blob을 찾지 못했다. 최종 guard, 선택 원본/Git 메타데이터13개 전후 비교, Buffer·FD 해제와 자식 종료를 확인했다. 이 결과는 관찰한 지원 저장소에서의 부재이며 저장소 전체 손상 여부의 판정은 아니다.
